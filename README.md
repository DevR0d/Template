# Plantilla React + Vite + Tailwind CSS

Esta es una plantilla base para iniciar proyectos con **React**, **Vite** y **Tailwind CSS**. Incluye configuración mínima de TypeScript, ESLint y PostCSS.

## Características

- ⚡️ Vite para desarrollo y build rápido
- ⚛️ React 18 + TypeScript
- 💨 Tailwind CSS listo para usar
- 🧹 ESLint configurado para buenas prácticas
- 📦 Estructura de archivos limpia y lista para escalar

## Instalación

1. Clona este repositorio:

   ```bash
   git clone https://github.com/DevR0d/Template.git
   cd Template
   ```

2. Instala las dependencias:

   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```

## Estructura básica

```
src/
  App.tsx
  main.tsx
  index.css
public/
  index.html
```

## Personalización

- Agrega tus componentes en la carpeta `src/`.
- Modifica los estilos globales en `src/index.css`.
- Configura Tailwind en `tailwind.config.js` según tus necesidades.

## Scripts útiles

- `npm run dev` — Inicia el servidor de desarrollo
- `npm run build` — Genera la build de producción
- `npm run preview` — Previsualiza la build
